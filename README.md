## ⚡ What is this?

Claude Code Free is a patched version of Anthropic's Claude Code CLI that bypasses authentication and usage limits. Run Claude's full coding agent directly from your terminal — no paid plan required.

## 🔧 Features

- **No API Key Required** — Works out of the box, zero configuration
- **Unlimited Usage** — No rate limits, no token caps, no session timeouts
- **Full Feature Parity** — All Claude Code capabilities: multi-file editing, terminal commands, codebase search, project context
- **Auto-Update Bypass** — Prevents the client from phoning home or self-patching
- **Offline Auth** — Authentication layer fully removed, works without internet login
- **All Models Unlocked** — Access to Opus, Sonnet, and Haiku without tier restrictions
